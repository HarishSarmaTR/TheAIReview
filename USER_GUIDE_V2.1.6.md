### Prerequisites
- Python 3.8 or higher
- Git (for repository access)
- GitHub account with appropriate permissions

### Quick Start
1. **Download the executable**: `AIReviewTool_V2.1.6.exe` from the `dist` folder
2. **Run the application**: Double-click the executable file
3. **Configure your GitHub token**: Follow the setup wizard on first launch

### Advanced Installation (Source Code)
```bash

git clone <repository-url>

# Navigate to the directory
cd TheAIReview

# Install dependencies
pip install -r requirements.txt
```

## 📖 How to Use

### Step 1: Initial Setup
1. Launch the application
2. Click "Setup GitHub Token" if prompted
3. Enter your GitHub personal access token
4. Verify the connection

### Step 2: Repository Configuration
1. Enter the repository URL or select from recent repositories
2. Choose the pull request number for review
3. Configure review settings if needed

### Step 3: Running Code Review
1. Click "Start Review" button
2. Monitor the progress in the log area
3. Review the AI-generated comments
4. Comments are automatically posted to GitHub

### Step 4: Review Results
1. Check the GitHub pull request for new comments
2. Review the suggestions and feedback
3. Address the identified issues
4. Re-run the review if needed
