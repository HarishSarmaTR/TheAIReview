🔧 Setup Instructions

1 GitHub Token Setup
Create a personal access token at GitHub Settings > Developer settings > Personal access tokens
Required permissions: repo, read:user, user:email

Step-by-step with screenshots:

Navigate to GitHub Settings > Developer settings

Select Personal access tokens > Tokens (classic)

Generate new token with required permissions

Important: After selecting the required permissions (repo, read:user, user:email), you must also configure SSO (Single Sign-On) authorization for your organization.

Look for the "Configure SSO" button next to your organization name and authorize the token for use with your Thomson Reuters organization.
2 OpenArena Token Setup
Get your OpenArena API token from the Thomson Reuters AI platform
https://dataandanalytics.int.thomsonreuters.com/ai-platform/
3 Save Tokens
Enter both tokens in the application and click "Save Tokens" to securely store them
Security: Tokens are encrypted and stored locally on your machine

📝 How to Use

1 Enter Repository Information
Type the repository name in format: owner/repository-name
Example: microsoft/vscode
2 Enter Pull Request Number
Enter the PR number (just the number, e.g., 1234)
3 Start Review
Click "Start AI Review" to begin the analysis process
4 Monitor Progress
Watch the progress bar and activity log for real-time updates
5 View Results
Check the generated report and view metrics in the right panel

🎛️ Interface Guide

Application Interface Overview

Main interface showing token management, repository selection, and progress tracking

Left Panel - Controls

  • Token Management: Secure storage of your API tokens
  • Repository Selection: Recent repositories dropdown for quick access
  • Progress Tracking: Real-time progress bar with percentage display
  • Action Buttons: Start review, view PR, open reports

Right Panel - Activity & Metrics

  • Activity Log: Real-time updates with timestamps
  • Clear Function: Reset log and metrics with one click
  • Review Metrics: Time taken and estimated cost tracking
  • Report Access: Quick links to generated HTML reports

📊 Understanding Review Results

What the AI Reviews

  • Logic Errors: Faulty logic that could cause bugs
  • Security Issues: Potential vulnerabilities
  • Performance Problems: Significant performance impacts
  • Runtime Errors: Code that might crash or behave unexpectedly
  • Maintainability: Major readability and maintenance concerns

What the AI Ignores

  • Trivial style issues
  • Code that already follows best practices
  • Working test code and fixtures
  • Minor optimizations that would be premature
Pro Tip: The AI focuses on meaningful issues that matter for code quality and reliability

🔍 Troubleshooting

Common Issues

Token Errors: Ensure your GitHub token has the correct permissions.
AI Review Failed: Check your OpenArena API token and internet connection.
Comments Not Appearing on PR? Verify that the PR number and repository name are correct.

Getting Help

  • Check the Activity Log for detailed error messages
  • Use the Help menu in the application
  • For any issues, feel free to open an issue in the repo
  • Contact the Ultratax Team for support
