## 📋 Installation & Usage

### Quick Start
1. Download `AIReviewTool_V2.0.0.exe` from the release package
2. Launch the executable (no installation required)
3. Enter your GitHub Personal Access Token
4. Enter your OpenArena API token
5. Configure SSO settings in GitHub (see user guide)
6. Provide repository name and PR number
7. Click "Run Code Review" to start AI analysis

### Requirements
- Windows 10/11 (64-bit)
- Network access to GitHub and OpenArena APIs
- Valid GitHub Personal Access Token with repo access
- Valid OpenArena API token with Claude 4 Sonnet access
