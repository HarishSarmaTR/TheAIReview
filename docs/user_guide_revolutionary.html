📋 Overview

  • OpenArena account with API access (Thomson Reuters internal platform)

  • Proper network access to Thomson Reuters internal services

🚀 How to Use

Quick Start Guide

Enter Repository Information

Type your repository name in the format owner/repository-name (e.g., tr/cs-prof_tax-us-cstax-1040ST-AL). The tool remembers recently used repositories for quick access via the dropdown.

Specify Pull Request Number

Enter the PR number you want to review. You can find this in the GitHub URL (e.g., for /pull/123, enter 123) or in the pull request list.

Configure Review Options

Choose whether to post comments directly to the PR or just generate a local report. Check "Post to PR" to automatically add AI comments to GitHub for team visibility.

Start the Review

Click the "🚀 Review" button to begin the analysis. The tool will process all changed files and generate detailed, actionable feedback using Claude 4 Sonnet.

Understanding Results

⏱️ Review Time

Track how long the analysis takes. Larger PRs with more files will take longer to process, typically 1-3 minutes per file.

💰 API Cost

Monitor the cost of API calls to Claude 4 Sonnet. Costs are calculated based on token usage and displayed in real-time.

💬 Comments Posted

See how many review comments were generated and posted to the pull request, categorized by severity level.

⚙️ Advanced Settings

Access advanced AI configuration through Settings → AI Settings:

  • Temperature: Controls creativity vs. consistency (0.0-2.0, default: 0.7) - lower values are more focused
  • Top P: Controls response diversity (0.0-1.0, default: 1.0) - affects randomness in responses
  • Max Tokens: Maximum response length (1-200000, default: 16384) - limits review detail
  • System Prompt: Customize the AI's behavior and focus areas for specialized review needs

🔧 Troubleshooting Guide

🔐 GitHub Token Authentication Failed

Problem: Getting 401 authentication errors when trying to access repositories.

  • SSO Authorization: Ensure you've clicked "Configure SSO" → "Authorize" after creating your token
  • Token Permissions: Verify your token has "repo" scope for full repository access
  • Token Expiry: Check if your token has expired and create a new one if needed

🤖 OpenArena API Issues

Problem: OpenArena token extraction fails or API requests timeout.

  • 🔍 Check Network Connection: Ensure you can access Thomson Reuters internal network
  • 🔐 Verify SSO Session: Make sure you're logged into Thomson Reuters SSO
  • 🔄 Retry Token Extraction: Close browser and try the "Get-Token" button again

⚡ Performance & General Issues

Various performance problems and solutions:

  • Slow Performance: Restart the application and ensure you have adequate RAM available
  • Large PR Reviews: For PRs with 50+ files, expect longer processing times (5-10 minutes)
  • UI Not Responding: Wait for current operation to complete or restart the application
